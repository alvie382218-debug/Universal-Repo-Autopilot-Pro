# বাংলা ব্যবহারকারী গাইড

## টুলের উদ্দেশ্য

এই টুলচেইনটি GitHub repository-এ কাজ করে। এটি repository বিশ্লেষণ, setup সমাধান, security issue detection, এবং Bengali report generation সক্ষম করে।

## কীভাবে চালাবেন

```bash
chmod +x bin/*.sh
./bin/universal-autopilot-gen.sh https://github.com/owner/repo
./bin/security-scanner.sh /path/to/repo
./bin/report-generator.sh /path/to/repo /path/to/output.md
```

## কী কী সুবিধা আছে

- Repo intelligence
- Security scanning
- Setup support
- Report generation
- Developer productivity boost
- Bengali friendly output

## নিরাপত্তা নীতিমালা

- শুধুমাত্র authorized repository-এ ব্যবহার করুন
- exploit বা brute force করবেন না
- passive analysis থাকবে
- 로그 রাখুন
- sensitive data থেকে সচেতন থাকুন

## একটি ব্যবহারকারী-ভিত্তিক ব্যাখ্যা

আপনি যদি একজন ডেভেলপার বা ethical security analyst হন, তাহলে এই টুলটি আপনাকে দ্রুত বলে দেবে:

- প্রজেক্টটি কী ধরনের
- কী ভাষা ব্যবহার করছে
- কী dependency ব্যবহার করছে
- কোন অংশে নিরাপত্তার ঝুঁকি থাকতে পারে
- কিভাবে সেটাপ করতে হবে
- কীভাবে বাংলা রিপোর্টে তা উপস্থাপন করা হবে

## ফলাফল মানে কী

এই প্রকল্পের মূল মূল্য হলো: "speed + clarity + security + usability"।

এটি আপনার কাজকে অটোমেটেড করে এবং একইসাথে বেশি professional output তৈরি করে।
